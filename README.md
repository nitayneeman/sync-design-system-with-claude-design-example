# my-design-system

A minimal design system for syncing into Claude Design: three shadcn components (`Button`, `Card` and `Input`), Tailwind v4 and Storybook.

## Usage

```bash
npm install
npm run storybook
```

To compile the stylesheet:

```bash
npx @tailwindcss/cli -i ./src/index.css -o ./ds.css
```
